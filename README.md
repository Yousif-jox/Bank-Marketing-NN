# Bank Marketing Prediction Using Neural Networks

## Course Information
- **Course:** AIE231 – Neural Networks
- **University:** Alamein International University
- **Faculty:** Computer Science & Engineering

## Project Overview
This project aims to develop neural network models to predict whether a bank customer will subscribe to a term deposit based on customer information and previous marketing campaign interactions.

## Dataset
- **Name:** UCI Bank Marketing Dataset
- **Source:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/222/bank+marketing)
- **Records:** 45,211
- **Input Features:** 16
- **Target Variable:** `y`
- **Problem Type:** Binary Classification

## Project Objectives
1. Explore and analyze the dataset.
2. Clean and preprocess the data.
3. Build baseline machine learning models.
4. Design and train neural networks using TensorFlow/Keras.
5. Compare different architectures and hyperparameters.
6. Evaluate the models using classification metrics.
7. Develop an inference pipeline and a live demo.
